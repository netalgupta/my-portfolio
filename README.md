# Netal Gupta — Portfolio

A personal portfolio website built with **React + Vite**, featuring a typewriter hero, animated skill bubbles, project showcase, hackathons, certifications, and more.

## 🚀 Tech Stack

- **React 18** + Vite
- **CSS-in-JS** (inline styles + keyframe animations)
- **Vercel** for deployment

## 📁 Project Structure

```
netal-portfolio/
├── public/          # Static assets (images)
├── src/
│   ├── components/  # All section components
│   ├── App.jsx
│   ├── main.jsx
│   └── index.css
├── index.html
└── vite.config.js
```

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
